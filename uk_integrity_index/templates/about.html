ABOUT

About the project

A public-facing way to explore Members' registered financial interests and the output of a transparent, user-defined scoring methodology.

Data

This version of the website was generated from the two CSV datasets supplied for the project: the MP-level scoring file and the interest-level scoring file. The underlying register information originates from the UK Parliament's Register of Members' Financial Interests.

View Parliament's register archive →

Audit trail

Individual interest entries retain their Parliament Interest ID and register date. Profile pages link individual entries to the Parliament Interests API where available.

Scope

The uploaded dataset covers MPs and register entries from July 2024 onwards. This website reflects the files supplied to it; rerunning your Python data pipeline and replacing the data files is how the site can be refreshed.
